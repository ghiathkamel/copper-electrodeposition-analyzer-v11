# copper-electrodeposition-analyzer-v11
A numerical research prototype for modeling electrode geometry, solution composition, copper deposition, mass transport, idealized settling, thermal behavior, and power-supply constraints.

You can now:

• Predict if powder will float or sink
• Estimate suspension time
• Detect instability region
• See if PSU is limiting you
• Optimize acid concentration
• Predict if temperature will cause runaway
• Estimate real surface area produced
